# Bassic. 管理画面 操作マニュアル

この資料は、店舗側が普段見るための簡易マニュアルです。

普段の更新は、専用の管理画面だけで行います。専門的な設定は制作者または保守担当者が管理します。

## 渡されるもの

- 公開サイトURL
- 管理画面URL
- ログイン方法
- パスワード
- この操作マニュアル
- 困った時の連絡先

## 管理画面でできること

- TOPページの文章変更
- TOPページや各ページのメイン画像変更
- イベント情報の追加、編集、非公開
- フードメニューの名前、料金、画像変更
- ドリンクメニュー表の画像差し替え
- 貸切、二次会、機材レンタル情報の変更
- Instagram、Facebook、Xへのお知らせカード追加
- 住所、電話、営業時間、喫煙、テーブル・チャージの変更

## 普段は触らないもの

以下は制作者または保守担当者が管理します。

- サイト公開の裏側の設定
- 管理画面と公開サイトをつなぐ設定
- ドメインやURLの専門設定
- 検索エンジン向けの細かい設定

## 基本の流れ

1. 管理画面URLを開く
2. パスワードでログインする
3. 更新したい場所を大きなボタンから選ぶ
4. 必要な項目だけ入力する
5. 「プレビュー確認」で内容を見る
6. 「下書き保存」または「公開して反映」を押す
7. 数分後に公開サイトを確認する

## イベントを追加する

1. 管理画面で「イベント」を開く
2. 「イベントを追加」を押す
3. イベント名、日付、OPEN、START、出演者、料金、予約方法を入力する
4. 画像があれば追加する
5. 「公開する」をONにする
6. 保存する
7. 公開サイトのイベントページを確認する

下書きにしたい場合は「公開する」をOFFにします。

## メニューを変更する

1. 管理画面で「メニュー」を開く
2. 変更したいメニューを選ぶ
3. フード名、料金、画像を変更する
4. 「公開する」がONになっているか確認する
5. 保存する
6. 公開サイトのメニューページを確認する

料金を変えた後は、必ずスマホでも表示確認します。

## ドリンクメニュー表を差し替える

1. 管理画面で「ドリンク表」を開く
2. 差し替えたい画像を選ぶ
3. 新しい画像をアップロードする
4. 表示順を確認する
5. 保存する
6. 公開サイトで画像をクリックし、拡大表示も確認する

## 画像を差し替える

1. 管理画面で「画像」を開く
2. 使うページを選ぶ
3. 新しい画像をアップロードする
4. 表示順を確認する
5. 「公開する」をONにする
6. 保存する

横長で明るい写真を使うと、PCとスマホの両方で崩れにくくなります。
画像やPDFのURLを直接入れる場合は、`https://` から始まるURL、または `/assets/` から始まるサイト内URLを使います。

## SNSお知らせを追加する

自動タイムラインではなく、見せたい投稿やSNSページへ誘導するカードを作ります。

1. 管理画面で「SNSお知らせ」を開く
2. 「お知らせを追加」を押す
3. Instagram、Facebook、Xのどれかを選ぶ
4. タイトル、説明、リンクURL、日付を入力する
5. 「公開する」をONにする
6. 保存する
7. TOPページのSNS欄を確認する

Instagramの一覧表示を使う場合は、保守担当者が表示用URLを用意し、「TOP」のInstagram表示URLに入れます。

## 店舗基本情報を変更する

1. 管理画面で「店舗情報」を開く
2. 住所、電話番号、通常営業時間、イベント時の営業時間補足を確認する
3. 喫煙について、テーブル・チャージを必要に応じて変更する
4. Google Map URLとSNS URLを確認する
5. 保存する
6. 公開サイトで電話、地図、SNSリンクが開くか確認する

営業時間、料金、喫煙可否は来店判断に直結します。変更後は必ず公開サイトで確認してください。

## 反映されない時

保存してから公開サイトへ反映されるまで、数分かかることがあります。

確認すること:

- 保存ボタンを押したか
- 「公開する」がONになっているか
- 画像アップロードが完了しているか
- ブラウザを再読み込みしたか
- スマホでも確認したか

それでも反映されない場合は、制作者または保守担当者へ連絡します。
