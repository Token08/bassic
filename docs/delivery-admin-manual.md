# Bassic. 管理画面 操作マニュアル

この資料は、店舗側が普段の更新で使うための簡易マニュアルです。
専門的な設定や公開の裏側は、制作者または保守担当者が管理します。

画面には項目名と現在の内容を表示します。詳しい説明は「入力のヒント」「編集・保存の手順を見る」から開けます。保存・掲載でエラーが出ると、フォーム先頭のエラーへ自動で移動します。入力は残ります。直す項目名を押して入力欄へ移動し、修正後にもう一度操作してください。

## Facebookからイベントを追加する最短の手順

1. 左メニューの下にある「イベントを追加」を押します。
2. 開いた入力欄へFacebookの個別イベントURLを貼り、「Facebookから読み取る」を押します。
3. イベント名・日付・START・画像を確認し、不足や間違いを直します。登録済みの場合は、表示される「登録済みのイベントを編集」を押して確認します。
4. 「内容を確認してサイトに掲載」でプレビューを開き、確認後に「この内容で公開」を押します。確認画面を開いただけでは保存・公開されません。
5. 「公開サイトに反映されました」と出たら「SNS用の文面を開く」を押します。そのイベントのX・Instagram用下書きだけが表示されます。
6. 投稿先を選んで「投稿文をコピー」を押し、各SNSを開いて貼り付けます。画像を添付し、スタッフが投稿を確定します。自動投稿はしません。

サイトへの反映やSNS下書きの作成に失敗した場合は、画面のやり直しボタンを使います。同じイベントを新規登録し直す必要はありません。

「現在の内容を読み込めませんでした」と出た場合は、編集や保存はできません。通信を確認して「もう一度読み込む」を押してください。直らない場合は同じ内容を新規登録し直さず、表示されたメッセージを保守担当者へ伝えてください。

## 最初に確認するもの

- 公開サイトURL
- 管理画面入口URL
- ログイン方法
- パスワード
- 困った時の連絡先
- Google Calendar反映依頼先

店舗側に渡すURLは、基本的に「管理画面入口URL」だけです。
入口でパスワードを入れると、実際に編集する管理画面へ自動で移動します。
直接開ける編集画面URLを別で案内すると混乱しやすいため、通常は入口URLだけを案内してください。

## 管理画面でできること

管理画面の最初の画面では、TOP / EVENT / MENU / PARTY / ACCESS を左のページ一覧から更新したいページを選びます。
ページを選ぶと、そのページの中で編集できる「文字」「画像」「メニュー」「SNSお知らせ」などの項目へ進めます。

- TOPページの文章を変える
- TOPページや各ページのメイン画像を変える
- イベント情報を追加、編集、非公開にする
- フードメニューの名前、料金、画像を変える
- ドリンク表の画像を差し替える
- 貸切、二次会、機材レンタル情報を変える
- Instagram、Facebook、Xのお知らせカードを追加する
- 住所、電話番号、営業時間、喫煙、テーブル・チャージを変える

更新後に見るページは、管理画面の「確認するページ」から開けます。迷った時は次を目安にしてください。

| 更新したい内容 | 管理画面で選ぶ項目 | 確認するページ |
| --- | --- | --- |
| TOPの文章、初回来店向け文言 | TOPページ | TOP |
| TOPや各ページの大きい背景画像 | 画像 | 変更したページ |
| イベント情報、FacebookイベントURL | イベント | Event Schedule |
| フードメニュー名、料金、画像 | メニュー | Menu |
| ドリンク表画像 | ドリンク表 | Menu |
| 貸切、二次会 | 貸切 | Party & Rental |
| 機材レンタル、PDFリンク | 機材 | Party & Rental |
| Instagram、Facebook、Xのお知らせ | SNSお知らせ | TOPのSNS欄 |
| 住所、電話、営業時間、喫煙、チャージ | 店舗情報 | TOP、Access、Menu |

## 普段は触らないもの

以下は制作者または保守担当者が管理します。
管理画面では「保守向け設定」にまとまっています。分からない場合は変更しないでください。

- サイト公開の裏側の設定
- 管理画面と公開サイトをつなぐ設定
- ページ構成やセクションの表示順
- ドメインやURLの専門設定
- 検索エンジン向けの細かい設定

## 保守担当者に相談する時

次の場合は、無理に保存せず保守担当者へ相談してください。

- 「保守向け設定」を変更したい時
- Google Map、SNS、オンラインストアのURLが正しいか分からない時
- Instagramの一覧表示や外部サービスの設定を変えたい時
- 画像を入れても表示が崩れる時
- 公開後しばらく待ってもサイトが変わらない時
- FacebookイベントをGoogle Calendarにも載せたい時

## 基本の流れ

1. 管理画面URLを開く
2. パスワードでログインする
3. 更新したい場所を選ぶ
4. 内容を入力する
5. 「必須」の未入力が残っていないか確認する
6. URLや画像を入れた場合は「地図を開いて確認」「PDFを開いて確認」「SNSを開いて確認」「画像を開いて確認」など、入力欄の下に出る確認ボタンを押す
7. プレビューで内容と「公開前に確認」を見る
8. 途中なら「下書き保存」を押す。同じ端末の同じブラウザで続きを開けます
9. サイトに載せるときは、公開がONになっていることを確認して「プレビューして公開」へ進み、「この内容で公開」を押す
10. 「公開サイトに反映されました」と表示されたら「変更したページを開く」を押し、スマホでも同じページを確認する

慣れるまでは、一度にたくさん直さず、1〜2箇所ずつ変更して公開サイトで確認してください。
特に料金、営業時間、住所、電話番号、画像は来店判断に直結するため、大きく変える前に現在の画面をスクリーンショットで残しておくと安心です。

「公開前に確認」は、イベント、メニュー、店舗情報など、編集している内容に合わせて確認項目が変わります。
「確認するページ」は、いま編集している内容が反映される公開ページへの近道です。イベントならイベントページ、メニューならメニューページ、貸切ならパーティーページを開けます。公開後はPCだけでなくスマホでも見てください。

## 公開後の確認

「公開サイトに反映中」は、内容の保存が済んでサイトの更新を待っている状態です。画面を閉じても更新は続きます。管理画面に戻ると最後の公開操作を確認できます。
「公開サイトに反映されました」と表示されたら「変更したページを開く」と「表示の確認ポイント」を使ってください。「反映に失敗しました」と出たら、内容は保存済みです。「反映だけをやり直す」を押してください。再び失敗した場合は、その表示を担当者に伝えてください。

公開中の項目をサイトから外すときは、公開をOFFにして「プレビューして公開」へ進み、「保存して反映（この項目は非表示）」を押します。

イベントを公開したら、まずサイトのイベントページを確認してください。Google Calendarへの掲載が必要な場合は、イベント名・日付・開始時刻を保守担当者へ伝えてください。SNS向けに作った下書きは、投稿するSNSで内容と掲載結果を確認してください。

| 変更した内容 | 公開後に見る場所 | 見るポイント |
| --- | --- | --- |
| TOP文章、TOP画像 | TOP | 文字が読める、画像とロゴが被っていない |
| イベント | Event Schedule | 日付、START、料金、Facebookリンクが正しい |
| メニュー | Menu | 料理名、料金、画像が切れていない |
| ドリンク表 | Menu | 拡大しても文字が読める |
| 貸切、機材 | Party & Rental | 料金、PDFリンク、説明が古くない |
| SNSお知らせ | TOPのSNS欄 | 選んだSNSとリンク先が合っている |
| 店舗情報 | TOP、Access、Menu | 住所、電話、営業時間、喫煙、チャージが正しい |

公開サイトが変わらない時は、ページを再読み込みします。
それでも変わらない場合は、どのページを直したか、押したボタン、画面に出たメッセージ、スクリーンショットを保守担当者へ送ってください。

## 「公開する」と「プレビューして公開」の違い

- 「公開する」ON: その項目をサイトに出してよい状態です。公開後はサイトに表示されます。
- 「公開する」OFF: 下書き扱いです。まだサイトには出ません。
- 「下書き保存」: 管理画面には保存しますが、公開サイトへ反映しません。
- 「プレビューして公開」: 確認画面を見てから、公開サイトへ反映します。

「公開する」ONは、サイトへ出す準備ができた印です。ONにしただけでは公開サイトへ反映されないため、最後に必ず「プレビューして公開」まで押してください。
OFFのまま保存した項目は、管理画面には残りますが、お客様が見る公開サイトには出ません。

新しいイベント、メニュー、画像、SNSお知らせをサイトに出したい時は、「公開する」をONにしてから「プレビューして公開」を押してください。
公開できた後に表示される確認手順は、編集した内容に合わせて変わります。分からない時は、その表示どおりに公開ページを開いてください。

## イベントを追加する

1. 管理画面で「イベント」を開く
2. 「イベントを追加」を押す
3. イベント名、日付、OPEN、START、出演者、料金、予約方法を入力する
4. 画像があれば追加する
5. 「公開する」をONにする
6. プレビューして公開する
7. 編集画面の「確認するページ」からイベントページを開き、再読み込みして確認する

下書きにしたい場合は「公開する」をOFFにします。
公開するイベントは、日付とSTARTが必須です。
STARTは `19:00` のように半角数字と `:` で入力し、`START 19:00` のような文字は入れません。

## Facebookイベントから入力する

Facebookにイベントページがある場合は、手入力を減らせます。
Facebookのイベント一覧ページではなく、追加したいイベントを1件開いた時のURLを使います。

1. 管理画面で「イベント」を開く
2. 「新しく追加」を押す
3. 「FacebookイベントURL・詳細URL」にFacebookイベントページのURLを入れる
4. 「Facebookから読み取る」を押す
5. 読み取り結果のチェックリストを見る
6. タイトル、画像、日付、STARTが入ったか確認する
7. 日付またはSTARTが入らない場合は、日付とSTARTを手入力する
8. 料金、予約方法、出演者など足りない情報を入力する
9. 「公開する」をONにする
10. プレビューして公開する

読み取りに失敗しても、イベント名、日付、START、画像を手入力すれば保存できます。
FacebookイベントURLは、イベント一覧ページではなく、個別イベントページのURLを使ってください。
Facebookイベントは、公開前に日付とSTARTの両方が入っていないと保存時に確認メッセージが出ます。
Google Calendarへ反映したいイベントは、公開後に管理画面の「Google Calendar反映依頼メモ」で「コピーする」を押し、その内容を保守担当者へ送ってください。管理画面で保存しただけでは、Google Calendar本体は更新されません。

イベント公開後はサイト・Googleカレンダー・SNS下書きの結果を別々に確認します。X・Instagramは下書きの文面をコピーし、画像を添えてスタッフが投稿します。自動投稿はしません。SNS下書きだけ失敗した場合は「SNS下書きだけをやり直す」を押します。サイトを再公開せず、不足する投稿先の下書きだけを作り、編集済みの文面は残します。
Facebookから読み取れない場合でも、FacebookイベントURL、イベント名、日付、STARTを手入力すれば「Google Calendar反映依頼メモ」を使えます。
イベント名、日付、STARTが空欄の場合は「コピーする」が押せません。先にその3項目を入力してください。
依頼メモには「公開状態」も入ります。Google Calendarへ載せたい時は、「公開するON」になっていることを確認してから送ってください。公開するONになるまで「コピーする」は押せません。

## メニューを変更する

フードメニュー:

1. 管理画面で「メニュー」を開く
2. 変更したいメニューを選ぶ
3. メニュー名、料金、画像を変更する
4. 「公開する」がONになっているか確認する
5. プレビューして公開する
6. 編集画面の「確認するページ」からメニューページを開き、再読み込みして確認する

料金を変えた後は、必ずスマホでも表示確認してください。
料金は `1,200円` のような金額、または `時価`、`お問い合わせ`、`応相談` のように来店前に意味が分かる表記にします。
意味が分かりにくい文字だけの入力は、公開前に管理画面でエラーが出ます。

## ドリンクメニュー表を差し替える

1. 管理画面で「ドリンク表」を開く
2. 差し替えたい画像を選ぶ
3. 新しい画像をアップロードする
4. 「画像を開いて確認」で正しい画像が開くか確認する
5. 表示順を確認する
6. 「下書き保存」または「プレビューして公開」を押す
7. 編集画面の「確認するページ」からメニューページを開き、画像をクリックして拡大表示も確認する

## 画像を差し替える

1. 管理画面で「画像」を開く
2. 使うページを選ぶ
3. 新しい画像をアップロードする
4. 「画像を開いて確認」で正しい画像が開くか確認する
5. 表示順を確認する
6. 「公開する」をONにする
7. 「下書き保存」または「プレビューして公開」を押す

横長で明るい写真を使うと、PCとスマホの両方で崩れにくくなります。
TOPや各ページの大きい背景画像は、1600px以上の横長写真がおすすめです。ロゴや見出しが乗る左側に、重要な文字や顔が寄りすぎない写真を選んでください。公開後はPCとスマホで、ロゴ・見出し・ボタンと写真が被っていないか確認してください。
画像のURLを直接入れる場合は、`https://` から始まるURL、または `/assets/` から始まるサイト内URLを使います。
PDFのURLを直接入れる場合は、`https://...pdf` または `/assets/pdf/...pdf` の形にします。
URLを入れた後は、入力欄の下に出る「画像を開いて確認」または「PDFを開いて確認」を押して、正しいファイルが開くか確認してください。
画像をアップロードしただけでは公開サイトに反映されません。確認後に「下書き保存」または「プレビューして公開」を押してください。
画像を変えたい時は新しい画像を選び、画像を使わない時だけ「画像を外す」を押してください。
「画像の説明」は、検索や読み上げ用の短い説明です。画面に大きく表示される本文ではないため、写真に写っている内容を一言で書いてください。

## SNSお知らせを追加する

自動タイムラインではなく、見せたい投稿やSNSページへ誘導するカードを作ります。

1. 管理画面で「SNSお知らせ」を開く
2. 「お知らせを追加」を押す
3. 見せたいInstagram、Facebook、Xの投稿またはページURLを貼る
4. URLを貼るとSNS種別は自動で合います。画面に出るURL例を見ながら、タイトル、説明、日付を入力する
5. 「リンクを開いて確認」を押して、正しいSNSページや投稿が開くか確認する
6. 「公開する」をONにする
7. プレビューして公開する
8. TOPページのSNS欄を確認する

タイトルは6文字以上、説明は10文字以上を目安にします。
説明は1〜2文で「何のお知らせか」「どこを見てほしいか」が分かるように書くと、初めて見る人にも伝わりやすくなります。
タイトルと説明は、TOPページのSNSカードにそのまま表示されます。長い投稿本文を丸ごと貼らず、見てほしい内容がすぐ分かる短い案内にしてください。

リンクURLは、選んだSNSと同じサービスのURLを入れてください。
Instagramは `instagram.com`、Facebookは `facebook.com`、Xは `x.com` または `twitter.com` のURLを使います。

Instagramの一覧表示を使う場合は、保守担当者が表示用URLを用意し、「TOP」のInstagram表示URLに入れます。
通常のInstagramプロフィールURLではないため、分からない場合は空欄のままで大丈夫です。

## 店舗情報を変更する

1. 管理画面で「店舗情報」を開く
2. 住所、電話番号、通常営業時間、イベント時の営業時間補足を確認する
3. 喫煙について、テーブル・チャージが空欄になっていないか確認する
4. Google Map URLとSNS URLを確認する
5. URL欄の「地図を開いて確認」「SNSを開いて確認」を押して、地図やSNSが正しく開くか確認する
6. プレビューして公開する
7. 公開サイトで電話、地図、SNSリンクが開くか確認する

Google Map欄にはGoogle MapのURL、Instagram欄にはInstagramのURL、Facebook欄にはFacebookのURL、X欄にはXまたはTwitterのURLを入れます。違う種類のURLを入れると管理画面でエラーが出ます。

電話番号は数字が9桁以上含まれる形で入力します。
メールアドレスは `mail@bassic.jp` のように `@` とドメインを含む形で入力します。
数字の抜けや `@` の抜けがある場合は、保存前に管理画面でエラーが出ます。

営業時間、料金、喫煙可否は来店判断に直結します。変更後は必ず公開サイトで確認してください。

## 反映されない時

保存してから公開サイトへ反映されるまで、1〜3分ほどかかることがあります。公開サイトを開いたままの場合は、再読み込みして確認してください。

確認すること:

- 保存ボタンを押したか
- 「公開する」がONになっているか
- 「プレビューして公開」を押したか
- 画像アップロードが完了しているか
- ブラウザを再読み込みしたか
- スマホでも確認したか

保守担当者へ連絡する時は、次を一緒に伝えると確認が早くなります。

- どのページ、どの項目を変更したか
- 何を変更したか
- 「下書き保存」か「プレビューして公開」のどちらを押したか
- 押した時間
- 画面に出たメッセージ
- 可能であればスマホ画面のスクリーンショット

次の形で送ると、そのまま確認依頼として使えます。

```text
直したページ:
変更した内容:
押したボタン:
押した時間:
画面に出たメッセージ:
スクリーンショット: あり / なし
```

それでも変わらない場合は、保守担当者へ連絡してください。
