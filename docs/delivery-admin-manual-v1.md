# Bassic. 管理画面 操作マニュアル v1

この資料は店舗側へ渡すための簡易マニュアルです。

## 渡されるもの

- 公開サイトURL
- 管理画面URL
- ログインIDまたはログイン方法
- パスワード
- この操作マニュアル

GitHub、APIキー、ビルド設定は店舗側では触りません。

## 管理画面でできること

- TOPページの文章を変える
- TOPページや各ページのメイン画像を変える
- イベント情報を追加、編集、非公開にする
- フードメニューの名前、料金、画像を変える
- ドリンクメニュー表の画像を差し替える
- 貸切・レンタル情報を変える
- 機材レンタルPDFへのリンクを変える
- Instagram / Facebook / X のお知らせカードを追加する
- 住所、電話、営業時間、喫煙、テーブル・チャージを変える

## 触らない方がよいこと

- GitHub
- GitHub Actions
- Vercel
- APIキー
- セクションキー
- SEOの細かいURL設定

ここを触る必要がある場合は、制作者または保守担当者へ相談します。

## イベントを追加する

1. 管理画面で「イベント」を開く
2. 「追加」を押す
3. イベント名、日付、OPEN、START、出演者、料金、予約方法を入力する
4. 画像があれば追加する
5. 「公開する」をONにする
6. 保存する
7. 公開サイトで表示を確認する

下書きにしたい場合は「公開する」をOFFにします。

## メニューを変更する

フードメニュー:

1. 管理画面で「メニュー」を開く
2. 変更したい品目を選ぶ
3. メニュー名、料金、画像を変更する
4. カテゴリは `food` のままにする
5. 保存する

ドリンクメニュー表:

1. 管理画面で「ドリンクメニュー表」を開く
2. 新しい画像をアップロードする
3. 表示順を確認する
4. 保存する

## TOP画像を変更する

1. 管理画面で「メイン画像」を開く
2. `page` で `home` を選ぶ
3. 画像をアップロードする
4. 表示順を設定する
5. 「公開する」をONにする
6. 保存する

Events、Menu、Party、Accessも同じ操作で変更できます。

## SNS欄を更新する

自動タイムラインではなく、見せたい投稿やお知らせをカードとして登録します。

1. 管理画面で「SNSお知らせ」を開く
2. SNS種別を選ぶ
3. 表示タイトルを入れる
4. 投稿URLを貼る
5. 必要なら日付と説明を入れる
6. 「公開する」をONにする
7. 保存する

Instagramの一覧表示をしたい場合は、LightWidgetなど外部サービスで発行したiframe URLを「TOPページ」のInstagramウィジェットURLへ入力します。

## 店舗基本情報を変更する

1. 管理画面で「店舗基本情報」を開く
2. 住所、電話、営業時間、喫煙、テーブル・チャージを変更する
3. Google Map URLやSNS URLを確認する
4. 保存する

営業時間や料金は来店判断に直結するため、変更後は必ず公開サイトで確認します。

## 反映されない時

保存してから公開サイトへ反映されるまで、数分かかる場合があります。

確認すること:

- 保存ボタンを押したか
- 「公開する」がONになっているか
- 画像がアップロード完了しているか
- ブラウザを更新したか

それでも反映されない場合は、制作者または保守担当者へ連絡します。
