# Image Guidelines

画像は見た目と表示速度の両方に影響するため、管理画面やDrive素材から差し替える前に以下を目安にします。

## 推奨サイズ

| 用途 | 推奨サイズ | 目安容量 |
| --- | --- | --- |
| TOP / ページヒーロー | 横 1800-2200px | 250-600KB |
| メニュー画像 | 横 1200-1600px | 150-450KB |
| SNS / OGP | 1200 x 630px | 150-400KB |
| ヘッダー背景 | 横 1600-2000px | 150-500KB |
| Apple touch icon | 180 x 180px | 10-80KB |

## 運用ルール

- JPGは画質80-85程度を目安に圧縮します。
- 店内の雰囲気を見せる写真は暗くしすぎず、赤・黒・アイボリーのサイト色に合うものを優先します。
- メニュー画像は料理名や価格とセットで表示されるため、被写体が中央付近にある写真を使います。
- microCMSで画像を未設定にした場合、サイト側のカテゴリ別フォールバック画像が表示されます。
- 1枚あたり1MBを超える画像は、公開前にリサイズまたは圧縮します。
