# Bassic. サイト管理 引き渡しメモ

この紙は、納品先が普段の更新で見る情報だけをまとめるためのメモです。

## 開く場所

| 項目 | 内容 |
| --- | --- |
| お客様向けの公開サイト | [Bassic. 公式サイト](https://www.bassic.jp/) |
| スタッフ用の管理画面 | [Bassic. 管理画面](https://bassic-admin.vercel.app/) |
| ログイン方法 | 管理画面を開き、更新用パスワードを入れる |
| パスワード | 別送 |
| 困った時の連絡先 | 店舗で共有している連絡窓口を記入（確認待ち） |
| Google Calendar反映依頼先 | カレンダー担当の共有窓口を記入（確認待ち） |

普段の更新には「スタッフ用の管理画面」をブックマークしてください。

## 普段できること

- TOPページの文章を変える
- 写真を差し替える
- イベントを追加、修正、非公開にする
- FacebookイベントURLからイベントの入力を始める
- フードメニューの名前、料金、写真を変える
- ドリンク表の画像を差し替える
- 貸切、機材レンタル情報を変える
- SNSお知らせカードを追加する
- 住所、電話、営業時間、喫煙、テーブル・チャージを変える

## 更新した後に見る場所

- スマホでTOPページを見る
- メニューやイベントなど、変更したページを見る
- 店舗情報を変えた時は、スマホでAccessページも見る
- SNSお知らせを変えた時は、スマホでTOPページのSNS欄を見る
- 電話、地図、SNS、予約のボタンを押して確認する
- URLや画像URLを変えた時は、管理画面の確認リンクを押す
- SNSお知らせは、選んだSNSと同じURLを使う。Instagramは `instagram.com`、Facebookは `facebook.com`、Xは `x.com` または `twitter.com`
- 「公開する」がある項目は、掲載する場合にONになっているか確認する
- 下書きは保存した端末の同じブラウザから開く
- サイトに出すときは「公開する」をONにして、「プレビューして公開」から「この内容で公開」を押す
- 「公開サイトに反映されました」と表示されたら「変更したページを開く」を押す
- 反映に失敗したときは「反映だけをやり直す」を押す
- Facebookイベントから追加した時は、日付、START、画像が正しいか見る
- Facebookイベントから追加した時は、STARTが空欄のままになっていないか見る
- FacebookイベントURLは、イベント一覧ではなく個別イベントページのURLを使う
- FacebookイベントをGoogle Calendarにも載せたい時は、公開後に保守担当者へ連絡する
- 連絡する時は、管理画面の「Google Calendar反映依頼メモ」で「コピーする」を押して、その内容を送る
- 送付先は、上の「Google Calendar反映依頼先」に書いた連絡先を使う
- イベント名、日付、STARTが空欄だと「コピーする」は押せない

## Google Calendarにも載せたい時の連絡文

管理画面の「Google Calendar反映依頼メモ」で「コピーする」を押すと、次の形のメモをそのまま送れます。

```text
Google Calendarにも反映してください。
公開状態:
イベント名: 
日付:
START:
END:
FacebookイベントURL:
画像URL:
```

## 基本の流れ

1. スタッフ用の管理画面を開き、更新用パスワードを入れる
2. 左からページを選び、中央の公開ページで変更したい場所を押す。中央で選びにくいときは右の「編集箇所一覧」を開く
3. 右で現在の文言と写真を見て編集項目を選ぶ。中央の該当欄で「編集」を押す。途中で閉じるときは「下書き保存」を押し、同じブラウザで再開する
4. 「プレビューして公開」を押し、PC表示とスマホ表示を確認し、実際に掲載する内容が決まってから「この内容で公開」を押す
5. 「公開サイトに反映されました」と出たら、「表示の確認ポイント」を見る
6. 「変更したページを開く」から公開ページを開き、PCとスマホで確認する

慣れるまでは、1回の作業で変える場所は1〜2箇所にします。
料金、営業時間、住所、電話番号、画像を大きく変える前は、現在の画面をスクリーンショットで残してください。

## 反映されない時

公開を確定してからサイトへの反映まで数分かかります。「公開サイトに反映されました」と表示されたら、変更したページを開いて確認してください。
次を確認してください。

- 「この内容で公開」まで押したか
- 「公開する」がONになっているか
- 画像アップロードが完了しているか
- ブラウザを再読み込みしたか
- 編集画面の「確認するページ」から該当ページを開いたか
- 管理画面に出る「表示の確認ポイント」を見たか
- スマホでも確認したか

連絡する時は、どのページを直したか、何を変更したか、押したボタン、画面に出たメッセージ、可能ならスクリーンショットを一緒に送ってください。

## 反映されない時の連絡文

次の形で送ると、保守担当者が状況を確認しやすくなります。

```text
直したページ:
変更した内容:
押したボタン:
押した時間:
画面に出たメッセージ:
スクリーンショット: あり / なし
```

保存済みで反映だけ失敗した場合は「反映だけをやり直す」を一度押します。それでも変わらない場合は、同じ内容を新規登録せず、上の連絡先へ連絡してください。

## イベントを中止・取り下げる時

対象イベントの「公開する」をOFFにして公開を確定します。Google Calendarの予定はカレンダー担当に中止表示または取り下げを依頼してください。X・Instagramで告知済みの場合は、各SNSで案内を更新します。
