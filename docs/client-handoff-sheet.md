# Bassic. サイト管理 引き渡しメモ

> 旧画面の詳細資料です。現在の納品・操作手順は [Bassic_README_納品用.txt](Bassic_README_納品用.txt) を使ってください。以下の「反映依頼メモ」等の旧操作は現行画面にはありません。

この紙は、納品先が普段の更新で見る情報だけをまとめるためのメモです。

## 開く場所

| 項目 | 内容 |
| --- | --- |
| お客様向けの公開サイト | [Bassic. 公式サイト](https://www.bassic.jp/) |
| スタッフ用の管理画面 | [Bassic. 管理画面](https://bassic-admin.vercel.app/) |
| ログイン方法 | 管理画面を開き、更新用パスワードを入れる |
| パスワード | 別送 |
| 困った時の連絡先・公開失敗の通知先 | 店舗で共有している連絡窓口を記入（確認待ち） |
| Google Calendar反映依頼先・中止の連絡先 | カレンダー担当の共有窓口を記入（確認待ち） |

普段の更新には「スタッフ用の管理画面」をブックマークしてください。

## 普段できること

- TOPページの文章を変える
- 写真を差し替える
- イベントを追加、修正、非公開にする
- FacebookイベントURLからイベントの入力を始める
- フードメニューの名前、料金、写真を変える
- ドリンク表の画像を差し替える
- 貸切、機材レンタル情報を変える
- SNSお知らせカードを追加する
- 住所、電話、営業時間、喫煙、テーブル・チャージを変える

## 更新した後に見る場所

- スマホでTOPページを見る
- メニューやイベントなど、変更したページを見る
- 店舗情報を変えた時は、スマホでAccessページも見る
- SNSお知らせを変えた時は、スマホでTOPページのSNS欄を見る
- 電話、地図、SNS、予約のボタンを押して確認する
- URLや画像URLを変えた時は、管理画面の確認リンクを押す
- SNSお知らせは、選んだSNSと同じURLを使う。Instagramは `instagram.com`、Facebookは `facebook.com`、Xは `x.com` または `twitter.com`
- 「公開する」がある項目は、掲載する場合にONになっているか確認する
- 下書きは保存した端末の同じブラウザから開く
- サイトに出すときは「公開する」をONにして、「掲載前に確認」から「サイトに掲載」を押す
- 「公開サイトに反映されました」と表示されたら「変更したページを開く」を押す
- 反映に失敗したときは「反映だけをやり直す」を押す

## Facebookイベントを掲載する

1. 左の「イベントスケジュール」を選び、右の「編集箇所一覧」から「開催イベント」を開いて「Facebookイベント取り込み」を選びます。
2. Facebookの個別イベントページのURLを貼って「Facebookから読み取る」を押します。
3. イベント名、日付、START、画像をFacebookの表示と見比べます。空欄は入力し、違う項目は直します。「登録済みのイベントを編集」が出たら、そのボタンで開いて変更箇所を確認します。
4. 作業を中断するときは「この端末に保存」を押します。掲載するときは「公開する」をONにし、「掲載前に確認」から「サイトに掲載」へ進みます。
5. サイトへの反映が完了したら、スマホで「開催予定のイベント」を開きます。イベント名、日付、START、画像、詳細リンクを確認します。
6. X・Instagramの投稿を準備するときは、SNS欄で下書きを開きます。「投稿文をコピー」を押し、画像を確認して、投稿先を開きます。
7. カレンダーの表示が未確認で、掲載が必要な場合は、下の依頼メモを店舗のカレンダー窓口へ送ります。中止や掲載取り下げの場合も、同じ窓口に連絡します。

## Google Calendarにも載せたい時の連絡文

管理画面の「Google Calendar反映依頼メモ」で「コピーする」を押すと、次の形のメモをそのまま送れます。
イベント名、日付、STARTが空欄だと「コピーする」は押せないため、入力欄を確認してください。

```text
Google Calendarにも反映してください。
公開状態:
イベント名: 
日付:
START:
END:
FacebookイベントURL:
画像URL:
```

## 基本の流れ

1. スタッフ用の管理画面を開き、更新用パスワードを入れる
2. 左からページを選び、中央の公開ページで変更したい場所を押す。中央で選びにくいときは右の「編集箇所一覧」を開く
3. 右の「現在の内容」で文言と写真を確認し、「編集する」を押す。中央の該当欄で「編集」を押す。途中で閉じるときは「この端末に保存」を押し、同じブラウザで再開する
4. 「掲載前に確認」を押し、PC表示とスマホ表示を確認し、実際に掲載する内容が決まってから「サイトに掲載」を押す
5. 「公開サイトに反映されました」と出たら、「表示の確認ポイント」を見る
6. 「変更したページを開く」から公開ページを開き、PCとスマホで確認する

慣れるまでは、1回の作業で変える場所は1〜2箇所にします。
料金、営業時間、住所、電話番号、画像を大きく変える前は、現在の画面をスクリーンショットで残してください。

## 反映されない時

公開を確定してからサイトへの反映まで数分かかります。「公開サイトに反映されました」と表示されたら、変更したページを開いて確認してください。
次を確認してください。

- 「サイトに掲載」まで押したか
- 「公開する」がONになっているか
- 画像アップロードが完了しているか
- ブラウザを再読み込みしたか
- 編集画面の「確認するページ」から該当ページを開いたか
- 管理画面に出る「表示の確認ポイント」を見たか
- スマホでも確認したか

「反映だけをやり直す」を1回押しても失敗する場合は、表にある「困った時の連絡先・公開失敗の通知先」へ連絡してください。公開をやり直した時刻も控えます。

連絡する時は、どのページを直したか、何を変更したか、押したボタン、画面に出たメッセージ、可能ならスクリーンショットを一緒に送ってください。

## 反映されない時の連絡文

次の形で送ると、保守担当者が状況を確認しやすくなります。

```text
直したページ:
変更した内容:
押したボタン:
押した時間:
画面に出たメッセージ:
スクリーンショット: あり / なし
```

保存済みで反映だけ失敗した場合は「反映だけをやり直す」を一度押します。それでも変わらない場合は、同じ内容を新規登録せず、上の連絡先へ連絡してください。

## イベントを中止・取り下げる時

対象イベントの「公開する」をOFFにして公開を確定します。Google Calendarの予定はカレンダー担当に中止表示または取り下げを依頼してください。X・Instagramで告知済みの場合は、各SNSで案内を更新します。
