Bassic. サイト更新ガイド
2026年11月14日版

管理画面：https://bassic-admin.vercel.app/
公開サイト：https://www.bassic.jp/


【文章・写真を変える】
1. 左でページを選ぶ。
2. 中央のサイト表示で、変えたい場所をクリック。
3. 右で「文章」「写真・ロゴ」「カード」などを選び、中央で編集。
4. 下の「掲載前に確認」で、変更内容とPC・スマホ表示を確認。
5. 「サイトに掲載」を押す。反映完了後、公開サイトでも確認。

・画像は「写真・ロゴ」から対象を選び、差し替えます。
・カードは追加・複製・並び替え・非表示にできます。
・住所や営業時間は「共通設定から変更」を使います。他のページにも反映されます。
・色や余白などは「詳細な調整」。普段の更新では開かなくて大丈夫です。

【機材リストのPDFを変える】
「PARTY & RENTAL」→中央の「機材リスト詳細はこちら」をクリック
→右の「ボタン・リンク」で対象を選ぶ→「PDFを選ぶ」（3MB以内）。
「PDFを開いて確認」で中身を確認し、「掲載前に確認」から掲載します。
選んだだけではサイトの掲載先は変わりません。

【途中でやめる】
確定前の入力は保存されません。続けたい場合は画面を開いたままにしてください。
移動・終了するときは、入力が消える前に確認が出ます。

【イベントを追加する】
左の「イベントを追加」→Facebookの個別イベントURLを貼る
→「Facebookから読み取る」→同じ枠内で確認・修正
→「登録内容を確認」→「この内容で登録」。
サイト上に別のイベントカードは作らず、Googleカレンダーに表示します。
一覧ページのURLは使えません。URLがなくても手入力できます。

・イベント名・日付・開始時刻・画像URLを確認。不足は同じ枠内で入力します。
・OPEN＝開場、START＝開演。開始時刻が不明なまま掲載しないでください。
・出演者・料金・予約などは「詳細を追加」を開くと入力できます。
・終了時刻が未定なら、カレンダーは仮の2時間枠になります。登録前に確認できます。
・画像は「画像を開いて確認」で確認できます。画像URLがあれば保持されます。
・「登録済みのイベントを編集」が出たら、新しく作らずそちらを開きます。
・既存イベントは左の「イベントスケジュール」から選びます。
  一覧が見つからない場合は、右の「登録情報・非表示の項目」を開きます。

【店休日を追加・取り消しする】
左の「店休日を追加」で、お店の予定が見えるカレンダーを開きます。
日付を選ぶと「追加予定」。登録済みの店休日を選ぶと「取り消し予定」になります。
もう一度選ぶと選択解除。複数の日や別の月もまとめて選べます。
「変更を反映」→日付を確認→「この内容で反映」。「反映済み」を確認します。
連休や繰り返しの店休日も、選んだ日だけ取り消します。ライブの予定は変更しません。
失敗した日付は選択が残ります。「未完了分を再確認」を押してください。
「予定が変更されています」と出たときは、選択をクリアして読み直し、選び直します。
「結果を確認中」の間は、二重操作を避けるため選択を残してください。

【SNS・カレンダー】
イベント登録後、Googleカレンダーの「反映済み」を確認します。
SNSは次のボタンを使います。
・自動同期が接続済みなら、画面でカレンダーの「反映済み」を確認します。
  確認できない場合は「もう一度確認」「カレンダーだけ再反映」を使います。
・「自動同期は未接続」と表示されているときは「Googleカレンダーで確認・保存」で入力済みの予定を開きます。
  店舗用アカウントで開き、保存先を「Bassic」に選んで保存してください。
  開いただけでは保存されません。
  初回追加用のため、繰り返し保存すると重複します。変更・中止は既存の予定を編集します。
・登録完了画面の「SNSで使う」から、そのまま投稿の準備ができます。
  Xは「Xの投稿画面を開く」で文面入りの投稿画面へ進みます。
  Instagramは「文面をコピーしてInstagramを開く」→「作成」から画像を選び、文面を貼り付けます。
  画像は「画像をPCに保存」で用意できます。保存できない場合は「画像を開く」から右クリックで保存します。
  最後に各SNSで、店舗のアカウントを確認して投稿ボタンを押してください。
  文面を変えたい場合だけ「下書きを編集する」を使います。

【うまくいかないとき】
■ サイトが変わらない
反映には数分かかります。完了表示後、公開ページを再読み込みしてください。
確認画面で「サイトに掲載」を押すまでは反映されません。

■ 保存・掲載エラー
画面上部のエラーを確認し、指摘された欄を直します。
入力を失わないよう、すぐに画面を閉じたり再読み込みしたりしないでください。
「保存済み」と出た場合は「保存済みの内容を再反映」または
「反映だけをやり直す」を使います。同じ内容を新規登録し直す必要はありません。

■ 掲載したページ設定を戻したい
「ページ全体・検索表示」→「以前のページ設定を開く（最大3回）」。
開いただけでは掲載されません。ほかの箇所も戻るため、変更内容を確認して掲載します。
イベント・店舗情報などの登録データは戻りません。迷ったら下記へご連絡ください。

■ ログインできない・解決しない
上記の管理画面URLと共有パスワードを確認してください。
別サービスへの登録や契約は不要です。
解決しない場合は、この資料を送った納品担当者へ
「どのページで何をしたか」「発生日時」「画面全体の写真」を送ってください。
パスワードは写真・メッセージに含めないでください。
