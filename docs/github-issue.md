# 新規客・Google検索・Google Map流入を増やすBassic.サイトリニューアル

## 背景

現行サイトはイベント、メニュー、貸切、アクセス情報は掲載されているが、初めて来店する人が知りたい情報が分散している。Google検索やGoogle Mapから来た新規客が、店の雰囲気、価格感、場所、予約方法を短時間で判断しにくい。

## 目標

- Google検索・Google Map・SNSから来た新規客が30秒以内に「どんな店か」「今行けるか」「場所」「予約方法」を判断できる。
- 経営陣がブラウザの管理画面からイベント、画像、文言、メニュー、貸切プランを更新できる。
- 福岡・天神・親不孝通り・ミュージックバー・ライヴバー・貸切パーティーの検索導線を強化する。

## 実装方針

- Next.jsでSEOに強い静的生成サイトを構築する。
- microCMSを採用し、管理画面からイベント情報を最優先で更新できるようにする。
- `LocalBusiness` / `BarOrPub` の構造化データを追加する。
- Google Map導線として `Google Mapで開く`、`現在地から向かう`、埋め込み地図、駅からの徒歩情報を配置する。
- 店舗情報は `lib/site.ts` に集約し、表記ゆれを防ぐ。

## CMSで更新できる項目

- イベント情報: 日付、タイトル、出演者、開場/開演、料金、予約方法、画像、公開/非公開
- トップ: 画像、見出し、説明文
- 初めての方へ: 来店前の不安を減らす説明文
- メニュー: フード/ドリンク名、価格、説明
- 貸切プラン: プラン名、価格、説明
- アクセス補足: ビル5Fまでの案内やイベント日の注意

## SEO / Google Map施策

- title、description、見出しに `福岡 天神 ミュージックバー`、`親不孝通り バー`、`ライヴバー`、`貸切 パーティー` を自然に含める。
- OGP画像、canonical、robots.txt、sitemap.xmlを実装する。
- Googleビジネスプロフィールの写真、営業時間、カテゴリ、公式サイトURLを確認する。
- 来店後の口コミ依頼導線を店内POPやSNSで検討する。
