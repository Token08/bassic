# Bassic. 公開レビュー・掲載から拾った改善メモ

サイト本文では直接引用せず、傾向を要約して反映する。

## サイトへ反映した方向性

- 「天神・親不孝通り」「ミュージックバー」「ライブ・DJ」「貸切」「ファズカレー」を自然な検索語として各ページに残す。
- 初来店の不安を減らすため、営業時間、チャージ、喫煙可、Google Map、メール予約を見つけやすくする。
- 口コミや紹介記事で繰り返し見える魅力は、TOPページの `Review Signals` セクションに要約して配置する。
- Google Map検索向けに、住所、電話、営業時間、喫煙可、イベント日の営業時間変動を明示する。

## 注意点

- 外部媒体の営業時間や掲載情報は古い可能性があるため、最終公開前に店舗側の正しい情報を優先する。
- 口コミ本文は権利や文脈の問題があるため、サイト内では長文引用しない。
- Googleビジネスプロフィールの実レビューは、管理画面または公開Google Mapで最新内容を確認してから追加反映する。
