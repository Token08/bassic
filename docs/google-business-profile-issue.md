# Googleビジネスプロフィール改善: 検索・Google Map流入強化

## 目的
Google検索とGoogle Map検索から、福岡・天神・親不孝通りでミュージックバーやライヴバーを探している新規客が来店判断しやすい状態に整える。

## チェックリスト
- [ ] 公式サイトURLを公開URLに統一する
- [ ] 通常営業時間を `20:00 OPEN / L.O. 1:30 / 2:00 CLOSE` に揃える
- [ ] イベント日は営業時間が変動し、イベント後は22:30から通常営業になる旨を補足する
- [ ] 店内写真、外観/入口、バーカウンター、料理、ドリンク、ライヴ/イベント風景を追加する
- [ ] カテゴリを確認する（バー、ライヴバー、ミュージックバー相当）
- [ ] 公式サイト、Instagram、Facebook、X、オンラインストアのリンク表記を確認する
- [ ] Googleビジネスプロフィール投稿でイベント告知や営業情報を定期更新する
- [ ] 口コミ依頼導線を店内/サイト/SNSで作る
- [ ] 喫煙可、未成年入店不可、イベント中禁煙の場合ありの注意事項を必要に応じて明記する

## 公開前確認
- サイト側の構造化データ、canonical、sitemap、OGP、hreflangは正式URL確定後に最終確認する。
- Google Map上の営業時間・住所・電話番号がサイト表記と一致していることを確認する。
