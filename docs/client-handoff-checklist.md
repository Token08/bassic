# Bassic. クライアント引き渡しチェックリスト

このチェックリストは、ITリテラシーが高くない納品先へ渡す前の確認項目です。

## 渡すもの

- 公開サイトURL
- 管理画面URL
- ログイン方法
- パスワード
- 操作マニュアル
- 記入済みの引き渡しメモ
- 緊急連絡先または保守担当者の連絡先

## 渡さないもの

- サイト公開の裏側の設定画面
- 管理画面と公開サイトをつなぐ設定情報
- ドメインやURLの専門設定
- 検索エンジン向けの細かい設定

## 店舗側ができる更新

- TOPページの文章変更
- TOP/各ページの画像差し替え
- イベント追加、編集、非公開
- FacebookイベントURLからイベント追加
- フードメニューの名前、価格、画像変更
- ドリンクメニュー表の画像差し替え
- 貸切、機材レンタル情報変更
- SNSお知らせカード追加
- 住所、電話、営業時間、喫煙、テーブル・チャージ変更

## 店舗側に説明すること

- 保存後、公開サイトへ反映されるまで数分かかることがあります。
- 「公開する」がOFFの場合、サイトには表示されません。
- 「公開する」をONにしただけでは反映されません。最後に「プレビューして公開」を押します。
- 画像は明るく、横長のものを使うと崩れにくいです。
- 料金や営業時間を変えた後は、必ずスマホで表示確認します。
- URLや画像URLを入れた後は「リンクを開いて確認」「画像を開いて確認」を押します。
- SNSの完全自動タイムライン取得は外部サービス設定が必要です。通常運用ではお知らせカード方式が安定します。
- FacebookイベントURLから追加したイベントは、まずサイトのイベント情報として保存されます。Google Calendarへの反映は保守担当者が別途行います。
- 保守向け設定、外部サービス、URL判断で迷った時は保守担当者へ相談してもらいます。

## 初回レクチャーの流れ

1. 管理画面にログインしてもらう
2. イベントを1件追加してもらう
3. FacebookイベントURLからイベント追加を1回試してもらう。個別イベントページのURLを使うことも確認する
4. メニュー価格を1件変更してもらう
5. 画像差し替えを1回試してもらう
6. SNSお知らせカードを1件追加してもらう
7. URL入力欄の確認リンクを押してもらう
8. 「プレビューして公開」を押し、確認画面を見てから公開してもらう
9. 公開サイトで反映を確認する
10. 引き渡しメモを一緒に見て、公開サイト、管理画面、連絡先を確認する

FacebookイベントをGoogle Calendarにも載せたい場合は、イベント公開後に保守担当者へ「Google Calendarへ反映してください」と連絡してもらいます。

## 公開前チェック

- TOP / EVENT / MENU / PARTY / ACCESS がPCとスマホで崩れていない
- 電話、Google Map、Instagram、予約リンクが開く
- ドリンク画像モーダルが開く
- メニュー画像モーダルが開く
- Languageメニューが開く
- 営業時間、喫煙、テーブル・チャージが見つけやすい
- Google Mapで住所が正しい
- 本番URLが決まったら検索エンジン向けのURL設定を更新する
