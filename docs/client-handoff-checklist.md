# Bassic. クライアント引き渡しチェックリスト

このチェックリストは、ITリテラシーが高くない納品先へ渡す時のための確認項目です。

## 渡すもの

- 公開サイトURL
- 管理画面URL
- ログイン方法
- パスワード
- 操作マニュアル
- 緊急連絡先または保守担当者の連絡先

## 渡さないもの

- GitHubリポジトリ
- GitHub Actionsの設定画面
- Vercelの設定画面
- microCMS APIキー
- GitHubトークン
- `.env` ファイル

## 店舗側ができる更新

- TOPページの文章変更
- TOP/各ページの画像差し替え
- イベント追加、編集、非公開
- フードメニューの名前、価格、画像変更
- ドリンクメニュー表の画像差し替え
- 貸切・機材レンタル情報変更
- SNSお知らせカード追加
- 住所、電話、営業時間、喫煙、テーブル・チャージ変更

## 店舗側に説明すること

- 保存後、公開サイトへ反映されるまで数分かかることがあります。
- 「公開する」がOFFの場合、サイトには表示されません。
- 画像は明るく、横長のものを使うと崩れにくいです。
- 料金や営業時間を変えた後は、必ずスマホで表示確認します。
- SNSの完全自動タイムライン取得は、外部サービスやAPI設定が必要です。通常運用ではお知らせカード方式が安定します。

## 初回レクチャーの流れ

1. 管理画面にログインしてもらう
2. イベントを1件追加してもらう
3. メニュー価格を1件だけ変更してもらう
4. 画像差し替えを1回試してもらう
5. SNSお知らせカードを1件追加してもらう
6. 公開サイトで反映を確認する

## 公開前チェック

- TOP / EVENT / MENU / PARTY / ACCESS がPCとスマホで崩れていない
- 電話、Google Map、Instagram、予約リンクが開く
- ドリンク画像モーダルが開く
- メニュー画像モーダルが開く
- Languageメニューが開く
- 営業時間、喫煙、テーブル・チャージが見つけやすい
- Google Mapで住所が正しい
- 本番URLが決まったらcanonical、sitemap、OGP、hreflangを更新する
