# Bassic. クライアント引き渡しチェックリスト

このチェックリストは、ITリテラシーが高くない納品先へ渡す前の確認項目です。

## 渡すもの

- 公開サイトURL
- 管理画面URL
- ログイン方法
- パスワード
- 操作マニュアル
- 記入済みの引き渡しメモ
- 緊急連絡先または保守担当者の連絡先
- Google Calendar反映依頼先

## 渡さないもの

- サイト公開の裏側の設定画面
- 管理画面と公開サイトをつなぐ設定情報
- ドメインやURLの専門設定
- 検索エンジン向けの細かい設定

## 店舗側ができる更新

- TOPページの文章変更
- TOP/各ページの画像差し替え
- イベント追加、編集、非公開
- FacebookイベントURLからイベント追加
- フードメニューの名前、価格、画像変更
- ドリンクメニュー表の画像差し替え
- 貸切、機材レンタル情報変更
- SNSお知らせカード追加
- 住所、電話、営業時間、喫煙、テーブル・チャージ変更

## 店舗側に説明すること

- 保存後、公開サイトへ反映されるまで1〜3分ほどかかることがあります。公開サイトを開いたままの場合は再読み込みします。
- 「公開する」がOFFの場合、サイトには表示されません。
- 「公開する」をONにしただけでは反映されません。最後に「プレビューして公開」を押します。
- 「公開する」ONは表示許可、OFFは下書きです。ONは「公開後はサイトに表示されます」、OFFは「まだサイトには出ません」と説明します。サイトに出したい時はONにしてから「プレビューして公開」まで進めてもらいます。
- 慣れるまでは一度にたくさん直さず、1〜2箇所ずつ変更して確認します。
- 料金、営業時間、住所、電話番号、画像を大きく変える前は、現在の画面をスクリーンショットで残します。
- 公開後は編集画面の「確認するページ」から該当ページを開き、再読み込みして確認します。
- 公開後に管理画面へ出る「公開後の確認手順」を上から順番に確認します。
- 管理画面トップの「公開前に見る順番」から、TOP / EVENT / MENU / PARTY / ACCESSをPCとスマホで確認します。
- 画像は明るく、横長のものを使うと崩れにくいです。
- 「画像の説明」は検索や読み上げ用です。写真に写っている内容を短く書きます。
- 料金や営業時間を変えた後は、必ずスマホで表示確認します。
- URLや画像URLを入れた後は「リンクを開いて確認」「画像を開いて確認」を押します。
- SNSお知らせのURLは、Instagramなら `instagram.com`、Facebookなら `facebook.com`、Xなら `x.com` または `twitter.com` を使います。
- SNSの完全自動タイムライン取得は外部サービス設定が必要です。通常運用ではお知らせカード方式が安定します。
- FacebookイベントURLから追加したイベントは、まずサイトのイベント情報として保存されます。Google Calendarへの反映は保守担当者が別途行います。
- FacebookイベントURLから追加したイベントは、公開前に日付とSTARTが入っているか確認します。
- Google Calendar反映依頼メモに「公開状態: 公開するON」が入っているか確認してもらいます。
- 保守向け設定、外部サービス、URL判断で迷った時は保守担当者へ相談してもらいます。
- 反映されない時に連絡する場合は、どのページ、何を変更したか、画面に出たメッセージ、スクリーンショットを一緒に送ってもらいます。
- 管理画面の「Google Calendar反映依頼メモ」は「コピーする」を押して、そのまま保守担当者へ送ってよいことを説明します。
- Google Calendar反映依頼先は、引き渡しメモに記入してから渡します。
- 引き渡しメモの「反映されない時の連絡文」を、そのまま使ってよいことを説明します。

## 初回レクチャーの流れ

1. 管理画面にログインしてもらう
2. イベントを1件追加してもらう
3. FacebookイベントURLからイベント追加を1回試してもらう。個別イベントページのURLを使うことも確認する
4. メニュー価格を1件変更してもらう
5. 画像差し替えを1回試してもらう
6. SNSお知らせカードを1件追加してもらう
7. SNSお知らせで、選んだSNSとリンクURLの種類が合っているか確認してもらう
8. URL入力欄の確認リンクを押してもらう
9. 「プレビューして公開」を押し、確認画面を見てから公開してもらう
10. 編集画面の「確認するページ」から公開サイトを開き、反映を確認する
11. 公開後に出る確認手順を見て、PCとスマホで該当ページを確認してもらう
12. 管理画面トップの「公開前に見る順番」から、TOP / EVENT / MENU / PARTY / ACCESSを順番に開いてもらう
13. 引き渡しメモを一緒に見て、公開サイト、管理画面、連絡先、連絡文テンプレートを確認する

FacebookイベントをGoogle Calendarにも載せたい場合は、イベント公開後に管理画面の「Google Calendar反映依頼メモ」をコピーして保守担当者へ送ってもらいます。

## 公開前チェック

- TOP / EVENT / MENU / PARTY / ACCESS がPCとスマホで崩れていない
- 電話、Google Map、Instagram、予約リンクが開く
- ドリンク画像モーダルが開く
- メニュー画像モーダルが開く
- Languageメニューが開く
- 営業時間、喫煙、テーブル・チャージが見つけやすい
- Google Mapで住所が正しい
- 本番URLが決まったら検索エンジン向けのURL設定を更新する
